
# Sistem Informasi Manajemen Peralatan Laboratorium

Sistem informasi untuk mengelola peminjaman dan inventaris peralatan laboratorium berbasis web. Dibangun menggunakan PHP, MySQL, dan Bootstrap.

🚀 Fitur Utama

- Dashboard dengan statistik real-time
- Manajemen inventaris laboratorium
- Sistem peminjaman peralatan
- Tracking peminjaman aktif
- Sistem pelaporan kerusakan
- Manajemen denda keterlambatan

💻 Teknologi yang Digunakan

- PHP 7.4+
- MySQL 5.7+
- Bootstrap 5
- Font Awesome 5
- jQuery 3.6.0

📦 Struktur Database

- Laboratorium: Menyimpan data laboratorium
- Peralatan: Inventaris peralatan lab
- Peminjaman: Record peminjaman
- Laporan: Pelaporan kerusakan/masalah
- Denda: Manajemen denda keterlambatan

🛠️ Panduan Instalasi

1. Clone repository ini
2. Import file SQL ke database MySQL
3. Konfigurasi koneksi database di `config/database.php`
4. Jalankan di web server (Apache/Nginx)

📝 Fitur per Halaman

 Dashboard

- Statistik total laboratorium
- Jumlah peralatan
- Peminjaman aktif
- Laporan pending
- Aktivitas terbaru
- Denda belum dibayar

 Laboratorium

- Daftar laboratorium
- Detail fasilitas
- Jadwal penggunaan

 Peralatan

- Inventaris lengkap
- Status ketersediaan

- Kondisi peralatan

 Peminjaman

- Form peminjaman
- Status peminjaman
- Riwayat peminjaman
